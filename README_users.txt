Cosplay Studio 1.0.1 - give every outfit and haircut its own world animations (Clair Obscur: Expedition 33)
==========================================================================================================
1. Unzip anywhere and run "Cosplay Studio.exe" (nothing to install).
2. Pick a character, then an outfit or haircut. For Idle / Walk / Run / Sprint press Choose... and pick an animation
   (search by name or owner; "Use enemy / NPC set" fills idle + walk + run in one go). Keep = the item's own animation.
   Outfits win over haircuts for the same group (idle, walk+run, sprint).
3. File > Save project to keep your work (saved in the Projects folder next to the exe).
4. Build > Build mod. Name it, tick the zip box for Vortex, press Build. The result goes to the Builds folder
   (change it in File > Settings).
5. Install: add the .zip in Vortex, or copy the .pak / .utoc / .ucas into
   ...\Expedition 33\Sandfall\Content\Paks\~mods
Only one Cosplay Studio mod can be active at a time (put everything in one project). It replaces
BP_CharacterSkinComponent, so it conflicts with other mods that change that file.
Animations marked with a warning are known to look wrong on heroes.
